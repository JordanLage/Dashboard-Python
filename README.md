# Dashboard de Vendas de Chocolates

Este projeto é uma dashboard interativa desenvolvida em **Python** com o uso do **Streamlit**, baseada em um conjunto de dados do [Kaggle](https://www.kaggle.com/) sobre **vendas de chocolates**. O principal objetivo é explorar e visualizar os dados de forma intuitiva e interativa.

---

## Tecnologias Utilizadas

- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/) – criação da interface da dashboard
- [Pandas](https://pandas.pydata.org/) – manipulação e análise de dados
- [Seaborn](https://seaborn.pydata.org/) – visualizações estatísticas
- [Matplotlib](https://matplotlib.org/) – criação de gráficos

---

## Funcionalidades

- Visualização tabular dos dados
- Gráficos interativos e informativos
- Filtros para análises personalizadas
- Layout simples e de fácil uso
